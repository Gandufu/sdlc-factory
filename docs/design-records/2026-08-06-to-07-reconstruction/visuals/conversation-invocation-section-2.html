第 2 节：Conversation 与 Invocation 模型

产品对话、CLI native session、一次模型调用、受控工程执行和人工 Gate 是五种不同事实，禁止再共用一个 Run 概念。

恢复与分支不变量
A

Resume Guard

Model、CWD、conversation cursor、CLI/Adapter version、workspace revision、permission/config digest 任一不安全变化，即创建新 binding generation 并冷重播。

B

失败重试

同一 Invocation 新增 Attempt；不会重复 USER Message，不会覆盖失败记录，也不会静默换 Runtime/Model。

C

显式分支谱系

Branch 保存 parent 与 fork message，不复制后假装无关系；冷重播使用确定性 transcript snapshot。

D

partial 输出

失败时保留为 INTERRUPTED Message/事件，仅供查看；默认不进入后续 transcript，除非操作者显式采纳。

删除当前错误语义

发送消息 ≠ ExecutionRun ≠ Handoff ≠ Gate ≠ Baseline。 普通消息最多产生 AgentInvocation；只有 Governance 命令才能创建受控 Run、Submission 和 Gate。
