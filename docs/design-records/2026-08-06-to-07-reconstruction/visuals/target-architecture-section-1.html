项目级 Runtime 规则
1

创建项目时选择

只展示探测成功且通过该 Adapter TCK 的 OpenCode、Codex 或 Claude Code。

2

项目内固定

所有 Conversation 使用同一 Runtime；每次 Invocation 仍固定实际 CLI 版本、Model、CWD、权限和资源摘要。

3

迁移必须显式

归档旧 binding，创建迁移记录并冷重播；禁止因失败静默切换 CLI 或 Model。

从 Open Design 提炼

  • Runtime definitions、探测与 fault isolation
  • CLI args/stdin/stream parser/handle resume
  • Resume Guard 与冷重播
  • Skill staging 与安全解包测试向量

明确不继承

  • Open Design 产品数据库与领域表
  • permissive Atom Pipeline
  • 全局 last-writer-wins Memory
  • permission bypass / auto-approve
  • 不完整 AppliedPluginSnapshot
