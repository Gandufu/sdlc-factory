技能：采用 Open Design 式受治理注入
  • 读取选定技能的完整正文，不依赖各命令行工具自行发现。
  • 附属文件复制到项目暂存区，禁止符号链接和路径穿越。
  • 正文、附属文件、来源、解析器版本和摘要全部固化。
  • 只注入本次明确选中的技能，不堆叠无关技能。
  • 实际生效内容进入调用尝试记录，可复查、可重放。
插件：受治理资源包
  • 可声明技能、提示词、模板、资产、校验器、MCP 与权限需求。
  • 解析阶段保持纯函数，不启动进程、不写项目目录。
  • 审批后才允许暂存资源或启动所需 MCP。
  • 清单摘要不能冒充完整内容摘要；每个生效字节单独寻址。
  • 不支持 Atom 推进生命周期，不接受缺失信号默认成功。

批准基线
唯一权威；任何记忆都不能覆盖
自动提取默认关闭；启用后只能生成“待确认”，经人工确认或确定性验证后才“生效”，并支持“已取代”和到期。
权限必须分五层留证

资源包提出什么 → 策略允许什么 → 命令行工具实际得到什么 → 操作系统真正限制什么 → 运行时真实做了什么。五者不能合并成一个“已授权”字段。
