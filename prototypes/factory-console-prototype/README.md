# Factory 工作台原型

> 一次性原型——用于验证 AI 软件工厂 v1.2 工作台的信息架构与交互，不是生产实现。

本版以已确认的 Factory 工作台视觉方向为基线，验证“以项目为中心的连续工作区”是否能减少页面跳转：

- 项目目录与“基本信息—选择模板—确认初始化”三步创建流程；
- 顶层保留项目、待处理和运行（Operations）三个入口；运行页是 `READY → RUNNING → WAITING_FOR_HUMAN → BLOCKED → COMPLETED` 的只读投影；
- 进入项目后，由项目会话树、当前会话工作面和项目交付状态构成连续三栏工作区；
- 左侧按项目列出持续主线、普通工作会话和嵌套子 Agent 会话，并提供搜索、新建和归档；
- 中间呈现所选 OpenCode Session 的消息、工具过程、产物和人工 Gate；右侧生命周期是 Factory 权威状态的只读投影；
- 项目配置是独立系统入口，不伪装成 Session；配置页覆盖 Agent、Skills、MCP、Plugins、权限和有效配置状态；
- 不同项目拥有独立的项目目录、配置、会话树和消息键，不复用同一工作区状态；
- 执行记录、证据、基线与文件随当前会话关联的阶段联动，不再作为平级顶层页面；
- 顶部容量抽屉只做轻量排队查看，完整运行投影由 Operations 承担；
- 产物、差异与人工裁决保留在中心工作面；
- Design Gate 同屏展示候选产物、差异、Handoff、确定性检查、环境、未决问题和 Evidence，并明确审核人与执行人；
- 阻塞恢复只允许复检后创建新 Run，不续接旧会话；
- 中间区域采用固定输入框的持续会话，可查看执行步骤、上传附件并发送消息；
- 一个项目工作会话可以关联多个 Run；子 Agent 使用可导航的 Child Session，生命周期阶段不强制等于 Session；
- 可切换历史 Session，查看当时的消息、执行摘要、产物和结果；历史记录只读，不能续接旧 Session 或重复执行 Gate；
- 阶段对话只用于提问、补充上下文和要求修订，不拥有批准、退回或接管权限。

会话工作面已经裁决采用 Codex 式连续会话流。会话栏、会话区和项目状态栏之间提供可拖拽分隔线，左右栏均有安全宽度限制，并支持方向键微调。

最终载体是 Electron 桌面应用。原型按 `1024 × 720` 最小可用窗口设计，推荐 Electron `BrowserWindow` 设置 `minWidth: 1024`、`minHeight: 720`：宽屏保留完整三栏；中等宽度压缩左右栏；接近最小宽度时左侧会话栏保持可用，右侧项目状态移动到中间工作面的下方。正文不低于约 `14px`，辅助信息不低于约 `12px`，不以手机端作为正式目标。

本轮不设置常驻控制台与终端；动态和诊断信息按当前阶段进入上下文检查器。日志不自动成为证据，也不能绕过人工裁决。会话历史、Run/Session 关系和历史事件均为静态样例；用户在输入框发送的原型消息只写入浏览器 `localStorage`，用于验证刷新后的交互感受，不代表 Factory PostgreSQL、StageConversation Projection 或 OpenCode Host Adapter 已实现。

